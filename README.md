# Learning-programming-langues


This repository is dedicated to learning and practicing different programming languages and concepts.  
It contains small projects, exercises, and experiments to improve coding skills and explore various technologies.

## Purpose

The main goal of this repository is to:
- Practice syntax and logic across different languages  
- Experiment with libraries, frameworks, and APIs  
- Build small test projects for hands-on learning  
- Keep code examples organized by language

## Structure

The repository is divided into folders by language:

- **/python** – scripts and small projects written in Python, used to explore data structures, automation, and general programming concepts.  
- **/nodejs** – examples and test projects built with Node.js, used to practice backend development, APIs, and JavaScript fundamentals.

## How to Use

Feel free to browse, modify, and run the code to experiment or learn from it.  

---

**Note:** This repository is not intended for production use — it's purely for learning and experimentation.
